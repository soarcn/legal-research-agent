# ADR-007: Holdout is consumed on first formal use

- Status: Accepted
- Date: 2026-08-31

The 20-case v1 holdout is used once for the authorized P8 release-candidate evaluation and is then marked consumed. Reshuffling or renaming the same 100 known questions does not create an independent holdout; another formal unseen evaluation requires newly acquired or independently authored cases that were not used for development, validation, or prior reporting.
